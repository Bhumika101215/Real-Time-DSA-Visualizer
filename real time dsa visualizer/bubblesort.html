Bubble Sort

lightbulb How it Works

Bubble Sort is a foundational sorting algorithm that works by repeatedly stepping through the list, comparing adjacent elements and swapping them if they are in the wrong order. The pass through the list is repeated until the list is sorted.

The algorithm gets its name because smaller or larger elements "bubble" to the top (the end of the list) with each iteration, much like bubbles rising in a glass of soda. While intuitive, it is generally inefficient for large datasets.
