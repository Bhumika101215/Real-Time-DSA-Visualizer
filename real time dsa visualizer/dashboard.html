This platform helps students understand different sorting algorithms. You can learn how each algorithm works, its logic, and its time complexity.

Available Sorting Algorithms

Bubble Sort

Compares adjacent elements and swaps them until the array is sorted.

Selection Sort

Finds the smallest element and places it in its correct position.

Insertion Sort

Builds the sorted array one item at a time.

Merge Sort

Uses divide and conquer technique to sort data efficiently.

Quick Sort

Selects a pivot element and partitions the array around it.

Heap Sort

Uses a heap data structure to sort elements efficiently.
