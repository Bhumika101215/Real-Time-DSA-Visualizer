Pivot Strategy

The efficiency of Quick Sort relies heavily on the selection of the pivot. A good pivot splits the array into two nearly equal halves, ensuring a logarithmic recursion depth.

def quick_sort(arr, low, high): # Base case: if low is less than high if low < high:
# pi is partitioning index, arr[pi] is at right place pi = partition(arr, low, high)
# Separately sort elements before and after partition quick_sort(arr, low, pi - 1) quick_sort(arr, pi + 1, high) def partition(arr, low, high): pivot = arr[high] i = low - 1 for j in range(low, high): if arr[j] <= pivot: i += 1 arr[i], arr[j] = arr[j], arr[i] arr[i + 1], arr[high] = arr[high], arr[i + 1] return i + 1

Divide & Conquer Flow

Step 01

Divide

Partition the array into two sub-arrays around a pivot element.

Step 02

Conquer

Recursively sort the left and right sub-arrays independently.

Combine
