Heap Sort

Binary Heap • In-place • Efficient Sorting Algorithm

How Heap Sort Works

Heap Sort first converts the array into a Max Heap. The largest element is moved to the end of the array. The heap size is reduced and the process repeats until all elements become sorted.

def heapify(arr,n,i):
    largest=i
    l=2*i+1
    r=2*i+2

    if larr[largest]:
        largest=l

    if rarr[largest]:
        largest=r

    if largest!=i:
        arr[i],arr[largest]=arr[largest],arr[i]
        heapify(arr,n,largest)
